# صورة برو 📄

موقع ويب مجاني 100% لتحويل صور الملازم والكشوف الورقية إلى ملفات PDF قابلة للطباعة — كل المعالجة تتم محلياً في المتصفح (بدون سيرفر).

## المميزات
- 📑 تحويل حتى 30 صورة إلى ملف PDF واحد بمقاس A4
- ✨ تحسين صور المستندات (إضاءة / تباين / أبيض وأسود)
- 🗜️ ضغط الصور مع الحفاظ على الجودة
- 🌙 وضع ليلي + تصميم متجاوب مع الموبايل
- 🔒 خصوصية كاملة — لا يتم رفع أي ملف على الإنترنت

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح، أو:
```bash
npx serve .
```

## النشر على Vercel
1. ارفع الملفات على مستودع GitHub جديد
2. ادخل على [vercel.com](https://vercel.com) وسجّل بحساب GitHub
3. اضغط **Add New → Project** واختار المستودع
4. اضغط **Deploy** — وهيكون موقعك شغال خلال ثواني ✅

## النشر على GitHub Pages
1. ارفع الملفات على المستودع
2. من **Settings → Pages** اختار الفرع `main` والمجلد `/ (root)`
3. الموقع هيكون متاح على `https://username.github.io/repo-name/`

## التخصيص
- روابط قنوات المجتمع (واتساب / فيسبوك / تليجرام): عدّلها من قسم `community` في `index.html`
- الألوان: عدّل المتغيرات في أول `css/style.css` (مثل `--primary`)
